# Muhammad Junaid Akbar — Portfolio

Personal portfolio built with plain HTML, CSS and JavaScript (ES modules). No build step.

## Run locally
Open the folder in VS Code and use the **Live Server** extension (ES modules do not load from `file://`), or:

```bash
python3 -m http.server 8000   # then open http://localhost:8000
```

## Structure
- `index.html` — markup
- `css/` — base, layout, components, sections, themes, responsive, print
- `js/` — one small module per feature, wired in `main.js`
- `assets/images/junaid-profile.png` — profile photo
